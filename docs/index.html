Windows installation and automatic sharing

All Windows packages save your settings and history in your user folder, not beside the program. No package needs administrator privileges to install. Quit the app before switching between x64 and ARM64; your saved settings and history stay available. Automatic sharing can be restricted when you copy from an app running as administrator; in that case, Clipboard Bridge may also need to run as administrator.

Your first connection

Three steps. Then start sharing.

Open the Windows app

Open Settings and choose Server mode. This simply lets your PC host the shared clipboard.

Connect your phone

Use the address shown by the Windows app in the Android settings or your two iPhone Shortcuts.

Send, then receive

Copy or share something on one device. Send it, then receive it on the other. The latest item is always the one you get.

Keep the PC and app running. Start with both devices on the same trusted Wi-Fi network.

Keep it within reach

Two Shortcuts for your Apple devices.

Load Clipboard sends. Download Clipboard receives. Use the same two actions for text, photos and files.

From another app: enable Show in Share Sheet to send a photo or file directly.

From iPhone Control Center: tap Add a Control, choose Shortcut and select each of the two actions.

Several files together: follow the grouped-file setup in the guide to keep them in one history item.

On Mac: build the same send/receive actions in Shortcuts using the server URLs in the guide. Run them when needed, or assign a keyboard shortcut. The distributed iPhone files have not yet been tested on a Mac; macOS support is through the workflow, not a native app or continuous background sync.

A few useful answers.

What can I share?

Text, links, images, PDFs and other file types. Several selected files can travel as one group. The newest item takes priority, not its file type.

Does sharing happen automatically?

Windows can automatically send and receive while the app runs. Android supports incoming notifications and sharing from other apps, but Android restricts background access to the clipboard. iPhone uses the two Shortcuts when you run them.

Can I share when I am away from home?

Yes, with a private VPN connecting your devices to the same private network. This also works when Windows hosts the clipboard. The guide includes an example; a VPN is optional for devices already on the same trusted network.

Do I need an account? Is my clipboard private?

No account or token is required. Transfers go through your own network, not to the project maintainers. Keep the service on a trusted network, rather than exposing it publicly.

If you use account or token URLs, the username, password and token are visible in plain text. Plain HTTP does not encrypt them. Use a trusted network, a private VPN or HTTPS.
