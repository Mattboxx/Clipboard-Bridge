Windows installation and automatic sharing

All Windows packages save your settings and history in your user folder, not beside the program. No package needs administrator privileges to install. Quit the app before switching between x64 and ARM64; your saved settings and history stay available. Automatic sharing can be restricted when you copy from an app running as administrator; in that case, Clipboard Bridge may also need to run as administrator.

Start with Windows

Same local network. Or a private VPN.

Your devices must be able to reach the clipboard host. At home, use the same trusted Wi-Fi/LAN. Away from home, connect through a private VPN, such as Tailscale. This works with both the Docker server and Windows Server mode. Tailscale is an example, not a requirement.

Want the same address at home and away? With a home server or NAS configured as a subnet router, a remote VPN-connected phone can keep using the server's local IP and port. The route must be advertised, approved and permitted; the router must stay on. Reserve the server's local IP so it does not change.

Do not expose port 5088 directly to the public internet. Subnet routing needs a separate VPN configuration; Clipboard Bridge does not enable it automatically. Connection and subnet-routing guide

Good to know

A few useful answers.

The essentials, before you start.

What can I share?

Text, links, images, PDFs and other file types. Several selected files can travel as one group. The newest item takes priority, not its file type.

Copied rich text arrives as plain Unicode text, retaining emoji and accents without fonts or colours. Actual documents, including RTF files, keep their original content.

Does sharing happen automatically?

Windows can automatically send and receive while the app runs. Android supports incoming notifications and sharing from other apps, but Android restricts background access to the clipboard. iPhone uses the two Shortcuts when you run them.

Can I share when I am away from home?

Yes. Use a private VPN, such as Tailscale, on your phone and clipboard host. This works with the standalone server and Windows Server mode. Use the host's VPN address, or configure subnet routing on your home server to keep using its local IP. See the network options.

Do I need an account? Is my clipboard private?

No account or token is required. Transfers go through your own network, not to the project maintainers. Keep the service on a trusted network, rather than exposing it publicly.

If you use account or token URLs, the username, password and token are visible in plain text. Plain HTTP does not encrypt them. Use a trusted network, a private VPN or HTTPS.
