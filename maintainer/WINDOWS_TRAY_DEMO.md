# Windows Tray Demo

## Origin

Recorded from the released Windows app (2.0.15) on 2026-10-15, with its actual
interface set to English. The person operating the PC opened the tray menu and
moved the pointer. No Send, Receive or History command was executed for this clip.
It demonstrates the tray controls, not an end-to-end transfer or a phone test.

## Privacy And Editing

- The original desktop recording is private and is not included in the repository.
- Only the native menu rectangle and the application's own tray icon are retained.
- The icon is a still crop from the same recording; the menu and pointer are moving
  native footage. Everything outside these two allowlisted regions is a solid matte.
- Other applications, the desktop, clock, network information and clipboard
  contents are excluded. No credentials or private addresses are displayed.
- The opening and early pointer movements were cut at the owner's request. The
  clip begins with the fully open English menu. Captions and an end hold were added.
- No application UI or transfer results were synthesized or translated in the image.
