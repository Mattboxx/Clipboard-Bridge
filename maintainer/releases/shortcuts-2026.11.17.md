## iPhone Shortcuts 2026.11.17

- **Load Clipboard** now runs from the Share Sheet and uses the current clipboard
  when started without input, for example from Control Center.
- Sharing a link that is a single `http://` or `https://` address sends the
  address as text instead of the downloaded page.
- The server address is requested while importing the Shortcut. Replace the whole
  example value with the address shown by Clipboard Bridge.
- **Download Clipboard** is unchanged and is included again so both Shortcuts
  share one download location.

This release contains only the two signed Apple Shortcuts. Windows stays at
**2.0.22**, and Android, Ubuntu, Docker and the App Store catalog are unchanged.

## Italiano

- **Load Clipboard** ora si avvia dal menu Condividi e, se avviato senza input
  (per esempio dal Centro di Controllo), usa gli appunti correnti.
- Condividendo un link che è un solo indirizzo `http://` o `https://`, viene
  inviato l'indirizzo come testo e non la pagina scaricata.
- L'indirizzo del server viene chiesto durante l'importazione. Sostituisci tutto
  il valore di esempio con l'indirizzo mostrato da Clipboard Bridge.
- **Download Clipboard** non cambia ed è incluso per avere entrambi i comandi
  nello stesso punto di download.

Questa release contiene solo i due Comandi Rapidi firmati. Windows resta alla
**2.0.22**; Android, Ubuntu, Docker e il catalogo App Store non cambiano.
