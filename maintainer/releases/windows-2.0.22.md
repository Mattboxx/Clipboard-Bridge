## Windows 2.0.22

- Choose the destination for newly received files in **Settings > General**.
  Select **Default** to return to `Downloads\Clipboard Bridge`. Existing files
  and settings stay where they are.
- When the Windows app is the host, **Settings > Connection** allows up to
  **1024 MiB** per upload and up to **300 seconds** of upload inactivity. Existing
  defaults stay at **256 MiB** and **30 seconds**. The upload limit also applies
  after ZIP expansion, and larger uploads can use more memory.
- Windows file transfers can wait longer for data. The standalone Docker limit
  remains independent.

Download either the installer or the portable EXE for your PC (x64 or ARM64).
The Windows executables are **unsigned**. Android, Ubuntu, Docker and the signed
iPhone Shortcuts have not changed.

## Italiano

- Scegli la destinazione dei nuovi file in **Impostazioni > Generale**. Con
  **Predefinita** torni a `Download\Clipboard Bridge`. I file già ricevuti non
  vengono spostati e le impostazioni esistenti vengono mantenute.
- Quando Windows fa da server, in **Impostazioni > Connessione** puoi impostare
  fino a **1024 MiB** per upload e fino a **300 secondi** di inattività. I valori
  predefiniti restano **256 MiB** e **30 secondi**. Il limite vale anche dopo
  l'estrazione dei gruppi ZIP; gli upload grandi possono richiedere più memoria.
- I trasferimenti file su Windows possono attendere più a lungo. Il limite del
  server Docker resta indipendente.

Scarica l'installer o il portable per il tuo PC (x64 o ARM64). Gli eseguibili
Windows **non sono firmati**. Android, Ubuntu, Docker e i Comandi Rapidi iPhone
firmati non cambiano.
